Datenmodell Nordlichter (Q138572984)

Das Datenmodell der Ausstellung „Nordlichter“ (Q138572984) basiert auf Wikidata und wird mit etablierten Metadatenstandards verglichen.

Beschreibung der Standards

Wikidata

Wikidata dient als Ausgangspunkt für die Modellierung. Die Ausstellung wird als Objekt (Q138572984) beschrieben und über Eigenschaften wie Titel, Ort, Zeitraum und Beteiligte charakterisiert.

Dublin Core

Dublin Core ermöglicht die Beschreibung von Kulturobjekten durch grundlegende Metadaten wie Titel, Ersteller, Datum und Sprache.

Schema.org

Schema.org beschreibt strukturierte Daten für Webseiten. Eine Ausstellung kann als Event modelliert werden.

CIDOC CRM

CIDOC CRM ist ein Standard für Kulturerbeinformationen. Die Ausstellung wird als Ereignis (E7 Activity) beschrieben und mit Orten, Personen und Zeitspannen verbunden.
